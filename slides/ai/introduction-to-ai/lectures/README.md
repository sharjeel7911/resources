## 📄 File Naming Convention

```
SE444_LXX[a-z]_description.pdf
```

| Component | Description | Example |
|-----------|-------------|---------|
| `SE444` | Course code | SE444 |
| `LXX` | Lecture number (00-13) | L07 |
| `[a-z]` | Part letter (for multi-part lectures) | a, b, c... |
| `description` | Brief topic description | propositional_logic |

### Examples

- `SE444_L00_course_overview.pdf`
- `SE444_L07a_knowledge_based_agents.pdf`
- `SE444_L11b_bayesian_networks_part2.pdf`

## 📋 Topic Details

### Foundations (L00-L02)
- **L00**: Course logistics, grading, resources
- **L01**: What is AI, history, applications
- **L02**: Agent types, environments, rationality

### Search & Problem Solving (L03-L06)
- **L03**: Uninformed search (BFS, DFS, UCS), Informed search (A*, Greedy)
- **L04**: Hill climbing, simulated annealing, genetic algorithms
- **L05**: Minimax, alpha-beta pruning, expectimax
- **L06**: CSP formulation, backtracking, constraint propagation

### Knowledge & Reasoning (L07-L09)
- **L07**: Propositional logic, inference, resolution, CNF
- **L09**: Classical planning, STRIPS, PDDL

### Probabilistic AI (L10-L12)
- **L10**: Probability theory, Bayes' rule, uncertainty
- **L11**: Bayesian networks, d-separation, inference
- **L12**: MDPs, value iteration, policy iteration

### Multi-Agent Systems (L13)
- **L13**: Game theory, Nash equilibrium, strategic interactions
