## 📋 File Naming Convention

All assessment files follow a unified naming scheme:

```
SE444_<TYPE>_[VARIANT]_<category>.pdf
```

### Components

| Component | Options | Description |
|-----------|---------|-------------|
| **TYPE** | `FINAL`, `MIDTERM01`, `MIDTERM02`, `QUIZ01-03`, `MOCK_FINAL` | Assessment type |
| **VARIANT** | *(none)*, `MAKEUP`, `v2` | Version or variant |
| **category** | `questions`, `solutions`, `answer_key`, `compact_solutions`, `formula_sheet`, `grading_guide` | Document type |

### Examples

- `SE444_FINAL_questions.pdf` - Final exam questions
- `SE444_MIDTERM02_MAKEUP_solutions.pdf` - Midterm 2 makeup solutions
- `SE444_MOCK_FINAL_formula_sheet.pdf` - Mock final formula sheet
