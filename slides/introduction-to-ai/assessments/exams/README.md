# 📋 Exams

This directory contains all exam materials organized by exam type.

## Contents

### Midterms
- **midterm01/** - First midterm exam materials
- **midterm02/** - Second midterm exam materials

### Final Exam
- **final_exam/** - Final exam materials including questions, solutions, and cheat sheets

### Additional Exams
- **makeup_exams/** - Makeup exam materials for students who missed the original exam
- **mock_exams/** - Practice exams for student preparation

## File Types

Each exam folder may contain:
- Questions PDF
- Solutions PDF
- Answer Key PDF
- Compact Solutions PDF
- Grading Guide PDF
- Formula/Cheat Sheet PDF
