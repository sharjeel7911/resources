# 🤖 Projects

This directory contains course projects for SE 444: Introduction to Artificial Intelligence.

---

## 📁 Current Projects

### 🎮 RoboMind Project

**Location:** `robomind_project/`

An intelligent agent simulation environment where students implement AI algorithms to control a robot navigating through various environments.

#### Objectives
- Implement search algorithms (BFS, DFS, A*)
- Apply logic-based decision making
- Use probabilistic reasoning for uncertainty
- Create hybrid intelligent agents

#### Components
```
robomind_project/
├── agents/               # Agent implementations
│   ├── search_agent.py       # Search-based agent
│   ├── logic_agent.py        # Logic-based agent
│   ├── probabilistic_agent.py # Probabilistic agent
│   └── hybrid_agent.py       # Combined approaches
├── ai_core/              # Core AI algorithms
├── maps/                 # Environment maps
│   ├── simple.txt
│   └── maze.txt
├── utils/                # Utility functions
├── environment.py        # Simulation environment
├── requirements.txt      # Python dependencies
├── PROJECT_OVERVIEW.md   # Detailed project description
├── QUICKSTART.md         # Getting started guide
└── README.md             # Project documentation
```

---

## 🎯 Learning Goals

Through the course projects, students will:

1. **Apply** search algorithms to real-world problems
2. **Implement** intelligent agents with different architectures
3. **Integrate** multiple AI techniques (search, logic, probability)
4. **Evaluate** agent performance in various environments
5. **Document** and present their solutions

## 🚀 Getting Started

### Prerequisites
- Python 3.10+
- Required packages: `pip install -r requirements.txt`

### Running a Project
```bash
cd robomind_project
python main.py --agent search --map simple
```
