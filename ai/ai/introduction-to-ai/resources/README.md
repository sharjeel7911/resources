## 💻 Code Examples

Sample implementations of key AI algorithms:

| Topic | Files | Description |
|-------|-------|-------------|
| Search | `bfs.py`, `dfs.py`, `astar.py` | Graph search algorithms |
| Local Search | `hill_climbing.py`, `simulated_annealing.py` | Optimization algorithms |
| CSP | `backtracking.py`, `ac3.py` | Constraint propagation |
| Logic | `resolution.py`, `cnf.py` | Logical inference |
| Planning | `strips.py`, `graphplan.py` | Planning algorithms |
| Probability | `bayes.py`, `bayesian_network.py` | Probabilistic reasoning |
| MDP | `value_iteration.py`, `policy_iteration.py` | Decision processes |
